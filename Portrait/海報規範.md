## 🎨 核心色票

### 四色系基礎 (Primary Color Palette)

| 用途 | 英文名稱 | 十六進制 | RGB | 應用場景 |
|------|--------|--------|-----|--------|
| **主色調** | Deep Navy Blue | `#1B325F` | 27, 50, 95 | 大標題底色、區塊外框粗線、強調型文字、表格邊界 |
| **次要色** | Muted Gray-Blue | `#5C7A99` | 92, 122, 153 | Mamba 模塊、次要架構圖、中性強調、表格分割線 |
| **強調色** | Academic Orange | `#D86C4F` | 216, 108, 79 | TuckerMoE 核心、最佳數據標示、關鍵對比、警示色 |
| **森林綠** | Forest Green | `#1B5E34` | 27, 94, 52 | 正面結果、結論、對比強調、成功指標 |

### 中性與背景色 (Neutral & Background)

| 名稱 | 十六進制 | RGB | 用途 |
|-----|--------|-----|------|
| 純白 | `#FFFFFF` | 255, 255, 255 | 主要背景、卡片底色、內容區域 |
| 極淺冰藍灰 | `#F4F7F9` | 244, 247, 249 | 次級背景、圖表背景、失效區塊底色 |
| 深炭灰 | `#333333` | 51, 51, 51 | 正文文字、連線、一般標籤（非純黑，降低對比刺眼感） |
| 淡灰 | `#E0E0E0` | 224, 224, 224 | 未激活區塊、禁用狀態、邊界輔助線 |
| 中灰（評論/註解） | `#5C7A99` | 92, 122, 153 | 圖例、小註解、透析文字 |

### 色票應用拆解

```
🔷 深海軍藍 #1B325F — 權威性、專業度、邊界定義
   ├─ 大標題底色背景：主海報標題、區塊標題
   ├─ 邊框：最外圍框線、關鍵分隔線（≥2.5px 粗度）
   ├─ 文字：強調數據、結論句
   └─ 表格：標題行背景、邊界線

🔹 莫蘭迪灰藍 #5C7A99 — 連貫性、柔和感、架構層級
   ├─ Mamba-3 模塊：所有 SSM 塊填充色、邊框色
   ├─ 表格：行分隔線（0.8px～1.2px）、次級標籤
   ├─ 輔助線：軟虛線、流程圖連接
   └─ 圖例：中性說明符

🟠 學術橘 #D86C4F — 視覺焦點、吸引注意、關鍵信息
   ├─ Tucker 核心張量：G_e 立方體、G_mix 色塊
   ├─ 最佳數據標示：「89.8%」、「3.32×」、「82.87%★」
   ├─ 警告/對比標籤：「Memory-bound ⚠」→「Compute-bound ✓」
   └─ 高亮背景：數據表格最佳行背景

🟢 森林綠 #1B5E34 — 正向指標、成功、結論
   ├─ 積極結果：「Zero expert collapse」、「✓ Mamba」
   ├─ 優化方向：綠色折線（訓練曲線）
   └─ 區塊對比：SOLUTIONS 段落主色

⚪ 純白 #FFFFFF — 乾淨、可讀、主視覺基底
   ├─ 所有卡片、區塊內部
   ├─ SVG 圖表背景（不使用淺黃、淺紫、淺藍）
   └─ 文本區域背景

🔘 極淺冰藍灰 #F4F7F9 — 微妙區隔、次級焦點
   ├─ 區塊標題背景（深色文字上）
   ├─ 表格隔行背景（避免完全白色單調感）
   └─ 圖表網格線背景（10% 透明度）
```

## 📝 排版與字體

### 字體系統

```
標題層級：
  ├─ 海報主標題（62.4pt）        → Times New Roman, bold, letter-spacing -0.3pt
  ├─ 副標題/變種（41.6pt）        → Times New Roman, bold, 色 #D86C4F
  ├─ 區塊標題（39.0pt）           → Helvetica/Arial, bold, 色 #1B325F
  ├─ 子標題（23.4pt）             → Helvetica/Arial, bold, 色 #1B325F
  ├─ SVG 內標題（15.5pt）         → Times New Roman, bold
  └─ 圖表軸標籤（8.5～10.4pt）   → Arial/Inter, sans-serif

正文：
  ├─ 卡片內文（19.5～28.6pt）    → Times New Roman, regular, 色 #333333
  ├─ 統計數據（36.4～62.4pt）    → 加粗，色 #1B325F 或 #D86C4F
  ├─ 表格內容（20.8pt）           → Times New Roman, regular
  └─ 腳註（15.6pt）               → Times New Roman, italic, 色 #5C7A99

特殊：
  ├─ 公式符號（LaTeX 風格）      → Times New Roman, italic
  ├─ 代碼/Monospace              → JetBrains Mono / Monaco, 色 #333333
  └─ 權重標籤                     → Inter, semi-bold, 色 #1B325F
```

### 行距與間距

| 元素 | 行距 | 外邊距 | 備註 |
|-----|-----|-------|------|
| 標題 | 1.08～1.15 | 4.5mm | 上下邊距相等，防止視覺不平衡 |
| 正文段落 | 1.3～1.6 | 1.8mm | 增加可讀性，確保清晰度 |
| 表格行 | 1.3 | 1.4mm（內）| 垂直對齊中心 |
| 卡片內部 | — | 2.5mm 左右 / 1.5mm 上下 | 均勻留白 |
| 區塊間距 | — | 4.5～5mm | 區塊標題後、區塊間距 |

## ✅ 實施清單

### 顏色一致性檢查清單

- [ ] 所有 Mamba-3 模塊：背景色 `#E8F1F8`，邊框色 `#5C7A99`，文字色 `#3D5A7F`
- [ ] 所有 Tucker 相關區塊：核心色 `#D86C4F`，淺背景 `#FFEDE6` 或 `#FFFFFF`
- [ ] 表格邊界線：`#5C7A99`（行分隔），`#1B325F`（外邊界）
- [ ] 數據標籤：最佳值背景 `#D86C4F`，文字色 `#1B325F`
- [ ] 正文文字：一律 `#333333`（不使用 `#000000`）
- [ ] 標題文字：一律 `#1B325F` 或 `#D86C4F`（強調）
- [ ] 背景填充：全部改為 `#FFFFFF` 或 `#F4F7F9`（不使用舊版的黃色、紫色等）
- [ ] SVG 圖表：檢查是否有遺漏的舊色碼（如 `#F0E6FF`, `#FFF8D0`, `#FEF3C7` 等）

### 排版一致性檢查清單

- [ ] 海報主標題：62.4pt, Times New Roman, bold, `#1B325F`
- [ ] 區塊標題：39.0pt, Helvetica Bold, `#1B325F`, 左邊 6px 邊框
- [ ] 正文：19.5～28.6pt, Times New Roman, `#333333`, 行距 1.3～1.6
- [ ] 統計數字：36.4pt+, bold, `#D86C4F` 或 `#1B325F`
- [ ] 表格：20.8pt, Times New Roman, 邊框 `#5C7A99` / `#1B325F`
- [ ] 所有邊框：最小 2px，重要邊界 2.5px～3.5px
- [ ] 陰影效果：`feDropShadow` 標準設定（dx=0, dy=1.5, stdDev=2, opacity=0.08）

### 視覺清潔度檢查清單

- [ ] 無純黑（`#000000`）或純白背景填充邊框，改用 `#1B325F` 和 `#FFFFFF`
- [ ] 飽和度統一降低，所有亮色改為莫蘭迪調（灰藍、学術橘而非亮紫、亮黃）
- [ ] 所有背景改為純白或極淺冰藍灰，無其他顏色背景層
- [ ] 連線和箭頭：根據優先級選擇 `#1B325F`（主）、`#5C7A99`（次）、`#D86C4F`（強調）
- [ ] 版面空白均勻：區塊間 4.5～5mm，卡片內 2.5mm 左右邊距
- [ ] 沒有視覺雜訊：禁用不必要的漸層、紋理、複雜陰影
