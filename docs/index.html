Mamba-3 SSM Blocks

Advanced selective State Space Model with trapezoidal discretization (Δt computed by trapezoid rule rather than zero-order hold), MIMO input/output projections, and chunk-wise parallel scan. Processes arbitrarily long sequences with O(1) recurrent decode state — enabling 32K context on a 16 GB M2 Pro.

Trapezoidal Δt MIMO proj Chunk-wise scan O(1) state 32K context

TuckerMoE Expert Blocks

Tucker tensor decomposition applied to every MoE expert: W ≈ G ×₁ U₁ ×₂ U₂ ×₃ U₃. 8 experts with top-2 routing, reducing 2.4B dense parameters to 417M (82.87% compression) while preserving 99.87% of representational accuracy (Tucker MSE 0.00135 vs SVD 0.00247).

Tucker Decomposition

Compress Without Compromise

Tucker decomposition factorizes each expert weight tensor into a compact core G and factor matrices U₁, U₂, U₃ — dramatically reducing parameter count while preserving model accuracy.

W ≈ G ×₁ U₁ ×₂ U₂ ×₃ U₃ W ∈ ℝ^{d×d} (original expert weight) G ∈ ℝ^{r₁×r₂×r₃} (Tucker core tensor) Uᵢ ∈ ℝ^{dᵢ×rᵢ} (factor matrices)

Why Tucker beats SVD: Tucker factorizes all modes simultaneously, preserving cross-mode structure that SVD's sequential rank-1 decomposition discards. Result: 45.3% lower reconstruction error at the same compression ratio.
Training Pipeline

3-Stage Progressive Curriculum

Progressive training starting from raw web data, refined through instruction alignment, and finalized with a novel 5-component Chain-of-Thought loss.

Custom dataset with <think>/<final> structured outputs. 5-component product loss enforces reasoning quality at each step.

Unified Memory
Zero-copy CPU↔GPU data sharing. KV cache stays in unified pool — no PCIe transfer penalty.
⚡
Metal Kernels
Custom fused Metal shaders for SSM scan and Tucker einsum. Moves MoE from memory-bound to compute-bound.
🔧
mx.compile
MLX graph compilation for decode loop. Compiled mode achieves 47→70 tok/s with bitwise-identical output.
🎯
N-gram Cache
3-strategy candidate pool: NGramCache (MRU 8192) + SuffixRetriever (PLD) + Runtime N-gram. Feeds Jacobi decode tree.
📦
O(1) State Memory
Mamba-3 recurrent decode: 14.1 MiB SSM state vs O(n) KV cache for Transformers. Constant memory at any context length.
🗜️
Asymmetric Quant
MoE experts quantized to 4-bit or 8-bit separately from attention layers — maximizing bandwidth without perplexity regression.
