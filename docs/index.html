Tucker Decomposition

The Core Innovation

Tucker factorizes each MoE expert weight tensor simultaneously across all modes — preserving cross-mode structure that SVD's sequential approach discards.

Uᵢ∈ℝdᵢ×rᵢ— factor matrices
