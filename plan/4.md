       Main Triton Directory (/triton/)

       Core Modules:

       1. softplus.py - Simple activation function wrapper
         - Softplus activation: log(1 + exp(x))
         - Triton 3.0+ vs older version compatibility
       2. k_activations.py - SwiGLU activation implementation
         - Forward: x * sigmoid(x) * y
         - Backward: Computes gradients for swish gating
         - Bidirectional gradient computation with optional output recomputation
       3. layer_norm.py - Full LayerNorm and RMSNorm implementations
         - Forward 1-pass kernel with dropout, residual, rowscale support
         - Parallel LayerNorm (x1 with weight1)
         - Backward kernel with gradient accumulation across SM blocks
         - Supports both LayerNorm and RMSNorm modes
         - Key math: xhat = (x - mean) * rstd; y = xhat * w + b
       4. layernorm_gated.py - Gated LayerNorm variant
         - Optional gating branch z: norm(x) * silu(z) or norm(x*silu(z))
         - Group normalization support
         - Both LayerNorm and RMSNorm modes with gating
       5. selective_state_update.py - Selective state update for SSM
         - Math: state = state * exp(Adt) + x * dt * B; out = sum(state * C) + xD
         - Supports skip connection (D) and gating (z)
         - dt softplus optional, dt bias support
         - Handles state batch indices for packed sequences
       6. ssd_bmm.py - Block matrix multiply for chunk operations
         - Forward: A @ B^T for chunk-wise attention (batch, seqlen, k) -> (batch, nchunks, chunk_size, chunk_size)
         - Backward: Computes dA and dB from dout
         - Supports causal masking and sequence indexing for packed sequences
         - Key: Uses tl.dot for efficient BMM with careful masking
       7. ssd_state_passing.py - State passing through chunk boundaries
         - Forward: Applies exponential decay between chunks: state = scale * state + new_state
         - Backward: Reverse cumsum for gradient propagation through states
         - Handles initial state and seq_idx for variable-length sequences
         - Critical for chunk-level SSM computation
       8. ssd_combined.py - Combined Mamba chunk-scan operation
         - Integrates: chunk_cumsum, chunk_state, state_passing, chunk_scan, bmm operations
         - Main function: _mamba_chunk_scan_combined_fwd/bwd
         - Supports optional D skip, Z gating, initial states, varlen sequences
         - Backward implements complex gradient flow through all components
       9. ssd_chunk_scan.py - Low-level chunk scanning kernel (107K file)
         - Forward scan: Computes output contributions from SSM states
         - Backward variants: bwd_dz, bwd_dstates, bwd_dC, bwd_dcb, bwd_ddAcs
         - Uses TMA descriptors for efficient tensor loading
         - Contains most complex tensor manipulation in the codebase
       10. ssd_chunk_state.py - SSM state accumulation within chunks (61K file)
         - Forward: Computes per-chunk states from B, x, dt, dA
         - Backward: dB, dC, dA gradients with careful decay handling
         - Varlen support with sequence indexing

       Mamba-3 Subdirectory (/triton/mamba3/)

       Specialized kernels for Mamba-3 with trapezoidal discretization and rotary embeddings:

       1. utils.py - Fast math functions
         - cos_approx, sin_approx, tanh_approx, sech2_approx - PTX inline assembly approximations
         - silu - Swish activation: x * sigmoid(x)
         - sigmoid_approx - Uses built-in for better performance
       2. angle_dt.py - Rotary angle cumulative sum
         - Forward: Accumulates angles with tanh(angle) * PI, applies mod 2π
         - Backward: Reverse cumsum with proper chain rule through tanh
         - Handles chunked computation for long sequences
         - Output states for recurrent inference
         - Math: angle_cumsum[i] = sum_{j=0}^i tanh(angle[j]) * dt[j] * π, mod 2π
       3. mamba3_siso_combined.py - Main Mamba-3 autograd wrapper
         - Wrapper around forward/backward kernels
         - Integrates: angle_dt, mamba3_siso_fwd, mamba3_siso_bwd, and helper kernels
         - Supports state passing for recurrent inference
         - Handles varlen sequences
         - Manages intermediate tensor saves for backward
       4. mamba3_siso_fwd.py - Mamba-3 forward kernel (35K file)
         - Key computation:
             - Phase 1: Preprocess Q/K with bias and rotary embeddings
           - Phase 2: Compute attention with SSM states: out = Q @ States^T * exp(decay) + intra-chunk(Q,K,V) + DV + qk_dotV
         - Decay: exp(A*dt) computed with exp2 for stability
         - Trapezoidal discretization: gamma and scale factors
         - TMA descriptor usage for efficient memory access
         - Stores intermediates (Q, K, decay, states) for backward
       5. mamba3_siso_bwd.py - Mamba-3 backward kernels (85K file)
         - dZ kernel: Computes gradient for Z gating: dZ = dO * O * sigmoid(Z) * (1 + Z * (1 - sigmoid(Z)))
         - dQKV kernel: Main backward - computes dQ, dK, dV from attention mechanism
         - dQKTheta kernel: Gradients through rotary embeddings and biases
         - dDT kernel: Time delta gradients from decay and trapezoidal factors
         - Reverse iteration through chunks for proper gradient flow
         - Handles state gradients for recurrent modes
       6. mamba3_siso_step.py - Single-step Mamba-3 (token generation)
         - For inference: processes one token at a time
         - Maintains SSM states, K states, angle states
         - Applies rotary embeddings incrementally
         - Computes: SSM_state = SSM_stateexp(Adt) + outer(V,K)dttrap; out = SSM_state @ Q
         - Supports all optional features (D, Z, biases, initial states)
       7. mamba3_mimo_utils.py - Multi-Input Multi-Output utilities (75K file)
         - Complex tensor manipulations for MIMO Mamba blocks
         - Contains large reference implementations
       8. mamba3_mimo_rotary_step.py - MIMO rotary embedding step (16K file)
         - Rotary embedding application for multi-input configurations
         - Supports batched and varlen processing
         - Pairwise vs. split rotation modes
