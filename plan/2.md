## 给 AI 看的工程说明书：将 Mamba 分块扫描的块间串行替换为并行前缀扫描

### 0. 背景与目标

我们有一个 MLX 实现的 Mamba 模型，使用分块扫描（chunk parallel scan）加速长序列。  
当前代码 `chunk_parallel_scan_mlx` 的主要结构：

- 块内（intra‑chunk）：用 Metal 定制 kernel 做顺序扫描（O(Lc)），单线程负责一个 (h, d) 维度，效果很好。
- 块间（inter‑chunk）：用 Python `for` 循环串行传递隐藏状态：

```python
h_prev = mx.zeros(...)
for c in range(nc):
    inter_chunks.append(h_prev)
    h_prev = h_prev * decay[:, c] + h_intra[:, c, -1]
```

这导致块数多时成为瓶颈，尤其是在 **投机解码验证** 中，需要对 K 个 token 批量扫描时，序列长度 = prefix_len + K，当 K 很大时块数显著增加。

**目标**：将上述块间串行循环替换为高效的 **并行前缀扫描（tree scan / parallel prefix scan）**，利用 Blelloch 或 Kogge‑Stone 算法在 GPU 上实现 O(log nc) 步。要求：

- 保持数值精度与原串行版本一致。
- 全部使用 MLX 操作（`mx.exp`, `mx.cumsum`, `mx.einsum`, 自定义 Metal kernel 可选）。
- 函数接口不变：`chunk_parallel_scan_mlx(u, dt_b, a_b, c_rotated, chunk_size)` 返回 `(y, final_state)`。
- 优化后的函数可直接被投机解码的 `verify` 路径调用（该路径传入 batch=1，序列长度 = prefix_len + K）。

---

### 1. 当前函数详细分析

**输入**：

- `u`: (B, L, H, N, P) — 输入投影，已经乘过 dt 和 B。
- `dt_b`: (B, L, H) — Δ \* B 向量。
- `a_b`: (B, L, H) — A 向量。
- `c_rotated`: (B, L, G, N, R) — C 投影，已做分组旋转。
- `chunk_size`: int。

**内部处理**：

1. 对 L 补零至 chunk_size 的倍数。
2. 计算 `log_alpha = dt_b * a_b`，并分块。
3. 块内扫描：用 Metal kernel 得到 `h_intra` (B, nc, Lc, H, N, P)。
4. 块间串行：`h_inter` (B, nc, H, N, P) 存储每个 chunk 的初始状态（即上个 chunk 的最终状态）。
5. 输出 y = y_diag + y_off，其中 y_off 使用 `h_inter` 和 `c_dec` 计算。

**性能问题**：步骤 4 的 Python for 循环在 `nc` 较大（例如长序列或大 K）时速度慢，且不能利用 GPU 并行。

---

### 2. 要实现的并行前缀扫描

需要计算序列 \( h*0, h_1, \dots, h*{nc-1} \)，其中：

- \( h_0 = 0 \)
- \( h*{c} = h*{c-1} \odot d*{c-1} + x*{c-1} \)，
  - \( d*c = \exp(\sum*{t \in \text{chunk } c} \text{la}) \) (decay of chunk c)
  - \( x*c = h*{\text{intra}}[:, c, -1] \) (最后一个时间步的隐藏状态)

这是一个经典的 **关联扫描（associative scan）**，可以用并行前缀算法。  
定义算子 \( \bullet \) 作用在二元组 `(carry, acc)` 上：  
\((c_a, a) \bullet (c_b, b) = (c_b \odot c_a, c_b \odot a + b)\)。  
这里 `carry` 是乘性衰减因子，`acc` 是累积状态。  
初始元素为 `(d_c, h_intra[:, c, -1])`，扫描后得到每个 chunk 的 `(累积衰减, h_inter)`。

**实现要求**：

- 使用 MLX 的并行操作实现此关联扫描。
- 可以利用 `mx.cumsum` 或自己构建一个 Blelloch 风格的 kernel。
- 数值稳定性：`log_alpha` 已进行 ±40 的裁剪，扫描时不需要额外 clip。
- 最终 `h_inter` 的形状应为 (B, nc, H, N, P)。
