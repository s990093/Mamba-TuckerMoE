## Slide 5：萬惡的起源：Softmax Attention (壹 — 意義與 QKV)
- Q：當步「問什麼」，q_i, Q ∈ R^(N×d_k)
- K：被比的「標籤」，k_j, logit = q_i^T k_j
- V：被讀出的內容，v_j, V ∈ R^(N×d_v)
- 嵌入→Q,K,V：Q = XW_Q, K = XW_K, V = XW_V（Multi-head = 多組平行）

## Slide 6：萬惡的起源：Softmax Attention (貳 — 公式與 N²)
- 公式：Attention(Q,K,V) = softmax(QK^T/√d_k) V
- 致命瓶頸：必須先形成全配對 logits 矩陣 QK^T，shape 為 N×N
- 時間複雜度 O(N² d_k)，空間 O(N²)
- 例：N=16k, FP16 → ~1 GB 量級

## Slide 7：複雜度災難：QK^T 的代價
- SVG 視覺化矩陣相乘：Q (N×d_k) × K^T (d_k×N) = N×N 矩陣（記憶體爆炸區）
- N=4,096 → 16M 元素；N=16,384 → 268M 元素
- 序列長度 N 每翻倍，記憶體與計算量增長 4 倍（二次方增長）
- 當 1k → 16k，計算量暴增 256 倍

## Slide 8：FlashAttention：硬體優化的極限
- 核心思想：IO-Awareness（記憶體感知），真正瓶頸在 GPU HBM↔SRAM 之間
- 透過 Tiling 區塊化，保留在 SRAM 內完成；數學上仍是 Exact Attention
- Linformer 替代路線：低秩矩陣近似（無法做到 O(1) 推論）
- 但 FlashAttention 解決不了：O(N²) 數學本質沒變、KV Cache 仍線性增長、邊緣裝置無法部署超長序列
- SVG 對比：硬體優化路線 vs 數學架構路線（根本性改變）

## Slide 9：推論的夢魘：KV Cache 問題
- 自迴歸生成時，每產生一個 token 都需與所有過去的 KV 重新計算注意力
- KV Cache 大小隨序列長度線性增長，每步推論計算量也隨之線性增長
- 記憶體佔用：O(N·d_k) per layer
- LLaMA-2 70B 在 4k context 時 KV Cache 就佔用 ~5GB
- SVG 圖表：標準 Transformer KV Cache 記憶體線性增長 vs 理想 O(1) 恆定水平線

## Slide 10：核心提問 — 我們能不能解開 Q 和 K 的綁定？
- 把訓練時複雜度降到 O(N)，推論時像 RNN 一樣 O(1) 狀態更新？
- 視覺：O(N²) Softmax Attention → O(N) Linear Attention

## Slide 11：Part 2 Divider
- 核心解密：Linear Attention 的數學推演
- 副標：從 Softmax 到 Kernel Trick，一步一步推導 O(N) 的魔法

## Slide 12：Step 1：重新審視 Attention 公式
- 矩陣形式拆解為逐元素求和形式：V_i = Σ sim(q_i, k_j)·v_j / Σ sim(q_i, k_j)
- 傳統 sim 函數：sim(q_i, k_j) = exp(q_i^T k_j / √d_k)
- 因為有指數函數 exp，無法把 q_i 從求和中提出來！

## Slide 13：插頁：QK^T logits 與因果遮罩
- Causal Softmax Attention 公式：加上遮罩矩陣 M（上三角位置設為 -∞）
- 視覺化 7×7 因果遮罩矩陣：下三角有效、對角自注意力、上三角未來/遮罩

## Slide 14：Step 2：Softmax 的限制
- 核心問題：exp(q_i^T k_j) ≠ f(q_i)·g(k_j) — 不可分離
- 指數函數特性：exp(a+b)=exp(a)·exp(b)，但 exp(a^T b) 不能簡單拆解
- 每個 q_i 都必須和所有 k_j 配對計算 → O(N²)

## Slide 15：Step 3：Kernel Trick（核方法）
- 引入特徵映射 φ(·)，替換 Softmax：sim(q_i, k_j) = φ(q_i)^T φ(k_j)
- ❌ 原始 Softmax：exp(q_i^T k_j)，不可分離 → O(N²)
- ✓ Kernel 形式：φ(q_i)^T φ(k_j)，獨立計算 → 可重新排列運算順序
- 只要 φ(·) 合法，就定義了一個合法的核函數

## Slide 16：Step 4：結合律的魔法 ✨
- 代入 Kernel 形式後，φ(q_i)^T 對求和變數 j 是常數 → 可提出求和符號
- 魔法公式：V_i = φ(q_i)^T Σ φ(k_j) v_j^T / φ(q_i)^T Σ φ(k_j)
- SVG 視覺化：(QK^T)V（先產生巨大 N×N 矩陣）→ Q(K^T V)（只產生極小 d×d 矩陣）

## Slide 17：Step 5：提取 Query — 降維打擊
- 分子：Σ φ(k_j) v_j^T → d_k × d_v 矩陣，與 N 無關
- 分母：Σ φ(k_j) → d_k 向量，同樣與 N 無關
- 計算一次，對所有 i 共享。遍歷 N 個 token 成本：O(N·d_k·d_v)

## Slide 18：Step 6：O(N) 複雜度正式達成 🎉
- Standard Attention：O(N² d) — 先算 QK^T (N×N)，再乘以 V
- Linear Attention：O(N d²) — 先算 K^T V (d×d)，再乘以 Q
- 比較表：時間複雜度、空間複雜度、中間矩陣大小、當 N ≫ d 時

## Slide 19：Step 7：特徵映射 φ(x) 的選擇
- 論文使用：φ(x) = elu(x) + 1
- 原因：非負性保證 (>0)、計算高效、梯度友善、簡潔
- ELU 定義：x>0 時為 x，x≤0 時為 e^x-1。加 1 把值域平移到 (0,+∞)
- 注意：這是效能略低於 Softmax 的主因；後續有 cosFormer、Performer 等改進

## Slide 20：Step 8：雙重視角 — Training vs. Inference
- Training Mode（平行化）：V = φ(Q)·(φ(K)^T V)，複雜度 O(N d_k d_v)
- Inference Mode（遞迴）：S_i = S_{i-1} + φ(k_i) v_i^T，複雜度 O(d_k d_v) per step
- 精髓：同一個模型，訓練時像 Transformer，推論時像 RNN

## Slide 21：Part 3 Divider
- Transformers are RNNs
- 副標：將 Linear Attention 無縫轉換為 RNN 的狀態更新形式 — 通往現代 SSM/Mamba 的關鍵橋樑

## Slide 22：因果遮罩 (Causal Masking) 的影響
- 完整 Attention（雙向）：求和範圍 j=1 到 N
- 因果 Attention（單向）：求和範圍變成 j=1 到 i（只能看到過去）
- 因為求和範圍上界隨 i 遞增，可寫成遞迴形式

## Slide 23：定義 RNN 的隱藏狀態 (Hidden States)
- 分子狀態 S_i = Σ_{j=1}^{i} φ(k_j) v_j^T ∈ R^(d_k×d_v)
- 分母狀態 Z_i = Σ_{j=1}^{i} φ(k_j) ∈ R^(d_k)
- 輸出：V_i = φ(q_i)^T·S_i / φ(q_i)^T·Z_i
- Σ 展開說明：S_1 = φ(k_1)v_1^T, S_2 = S_1 + φ(k_2)v_2^T, S_3 = S_2 + φ(k_3)v_3^T
- 如果照定義去算，第 100 步要算 100 次 — 需要遞迴形式！

## Slide 24：遞迴更新公式 — 分子 S_i
- S_i = S_{i-1} + φ(k_i) v_i^T
- 每步計算量：O(d_k·d_v) — 常數！
- 與傳統 RNN 對照：RNN = h_i = f(h_{i-1}, x_i)；Linear Attn = S_i = S_{i-1} + g(k_i, v_i)

## Slide 25：遞迴更新公式 — 分母 Z_i 與輸出
- Z_i = Z_{i-1} + φ(k_i)
- 最終輸出：V_i = φ(q_i)^T·S_i / φ(q_i)^T·Z_i
- 完整 RNN 更新流程：輸入(k_i,v_i,q_i) → 映射 φ(k_i),φ(q_i) → 更新 S_i, Z_i → 輸出 V_i

## Slide 26：先備知識：什麼是 RNN？
- RNN 用固定大小的隱狀態 h_t 在時間上傳遞記憶
- 一般形式：h_t = f_θ(h_{t-1}, x_t)，y_t = g_θ(h_t)
- 經典 Elman/Vanilla RNN：h_t = σ(W_h h_{t-1} + W_x x_t + b)
- 對照 Linear Attention：S_i = S_{i-1} + φ(k_i)v_i^T（加性增量 vs 非線性活化）

## Slide 27：真正的 RNN 誕生！
- 傳統 RNN (Elman, 1990)：非線性激活 → 梯度消失/爆炸、無法平行化訓練
- Linear Attention RNN (2020)：線性更新 → 穩定梯度、矩陣狀態高容量、可同時平行化訓練
- Key Insight：只要替換掉 Softmax 中的指數項，Attention 本質上就是一種 RNN 狀態更新

## Slide 28：推論階段的巨大優勢
- 空間：O(N) → O(1)，只需維護固定大小狀態
- 每步計算量：O(N·d) → O(d_k·d_v) 常數
- 不需要 KV Cache，推論延遲恆定
- 比較表：推論記憶體、每步計算量、KV Cache 需求、推論延遲

## Slide 29：小結：Linear Attention 的雙重性
- Training — Transformer 模式：完全平行化矩陣運算，V = φ(Q)·(φ(K)^T V_in)
- Inference — RNN 模式：逐 token 遞迴狀態更新，S_i = S_{i-1} + φ(k_i)v_i^T
- 這不是近似，而是數學上的等價

## Slide 30：反向傳播的挑戰：記憶體退化
- AutoDiff 盲點：框架必須保存所有時間步的隱藏狀態 S_1,S_2,...,S_N
- 記憶體變回 O(N·d_k d_v)，摧毀了固定記憶體優勢
- 解決方案：手動推導反向傳播公式，利用累積和 (Cumulative Sums)

## Slide 31：反向傳播：累積和的奇蹟
- 對 Query 梯度：∇_{φ(Q_i)} L = ∇_{V̄_i} L · S_i^T（直接利用已算好的 S_i）
- 對 Key/Value 梯度：包含 Σ_{j=i}^{N} φ(Q_j) ∇_{V̄_j} L^T — 反向累積和
- 🔴 **觀察紅色項：Σ_{j=i}^{N} (…)** <br>這是一個**反向的累積和**！我們只要從序列結尾 N 一路往回算到 1，維護一個類似 S_i 的狀態矩陣即可。**完全不需要儲存所有的中間狀態！**

## Slide 32：Algorithm 1：雙向 Cumulative Sums
- 前向傳播 (Forward Pass)：從 1→N 掃描，維護 S ← S + φ(K_i)V_i^T，輸出 V̄_i ← φ(Q_i)S
- 反向傳播 (Backward Pass)：從 N→1 反向掃描，維護 S̃ ← S̃ + φ(Q_i)∇L^T，計算梯度
- 時間 O(N·d²)，空間 O(N·d)（無需儲存 N 個 d×d 中間矩陣）

## Slide 38：Part 5 Divider

## Slide 39：Linear Attention 的致命傷
- 沒有遺忘機制 (No Forget Gate / No Decay)：所有過去資訊同等權重加進 S_i
- 理想改進：S_i = γ·S_{i-1} + φ(k_i) v_i^T，γ∈(0,1) 指數衰減
- 缺少的拼圖：加入遺忘機制 → 解決長序列記憶退化

## Slide 40：第二階段：記憶機制的進化
- RetNet (2023)：引入固定衰減矩陣 γ，三種計算模式 (Parallel/Recurrent/Chunkwise)
- Mamba-1 (2023)：連續時間動態系統，衰減係數 Ā 依賴於輸入 (Selective Scan)
- 演進脈絡：S_i = S_{i-1} + ... → RetNet + γ → Mamba Ā(x_t)

## Slide 41：Mamba-2：狀態空間對偶性 (SSD)
- Dao & Gu (2024) 證明：SSM ≡ Linear Attention ≡ Semiseparable Matrices
- 三者本質上都是操作同一類「半可分矩陣」
- 硬體利用率從 ~30% → ~75%，比 Mamba-1 快 2-8×
- 理論統一 + 硬體極致優化

## Slide 42：第三階段：Delta Rule 與 Gated Delta Networks
- Delta Rule：S_i = S_{i-1} + β_i φ(k_i)(v_i^T - φ(k_i)^T S_{i-1}) — 先計算預測誤差再修正（像 SGD）
- GDN：結合資料依賴門控 α_i ⊙ S_{i-1} + Delta Rule 精準寫入
- 最終形態：記憶體管理從被動累積 → 主動、精準、選擇性更新

## Slide 43：大一統視角：Test-Time Regression (2025)
- Stanford 最新研究：Sequence Layer = Memorization (Test-Time Regression) + Retrieval (Query Lookup)
- 所有架構都是 TTR 的不同形式：Linear Attention (固定步長 SGD)、RetNet/Mamba (加權迴歸+衰減)、GDN (完整線上 GD)、Softmax Attention (非參數核迴歸)、TTT (多步 GD+非線性)
- 選擇 3 個要素即可定義任何序列模型：① 迴歸權重 γ、② 記憶參數化 M、③ 優化演算法
